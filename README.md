## Project Overview

- Briefly describe the purpose of the project.
- Explain the story you are telling through the webpage and the key interactive elements.

For my website, I created recreated an interactive children's story called "The Loading Bar" that I originally made for a Design class I took over the summer. The story follows a computer loading bar that becomes frustrated because its job takes time. Throughout the story, the loading bar learns that every computer character has an important job and that waiting can be worth it.

My webpage uses scrolling as part of the storytelling. As the user scrolls through the story, the main loading bar at the top of the page gradually fills up and the percentage increases to match with the story. There is also a smaller loading bar during the story that fills as the user scrolls past that section.

At the end of the story, the loading bar reaches 100% and the user is asked to click on a folder, which plays a sound effect and reveals three photos with an animation. 



## Features

- List the key features of the project, including:
    - **Animations**: 
    - The title slowly bounces up and down when the page loads.
    - The folder at the end of the story continuously bounces.
    - The group of computer characters on Page 5 also has a bouncing animation.
    - Characters fade upwards when user scrolls past it using GSAP.
    - The three photos at the end fade and move upward when the folder is clicked.
    - The main and mini loading bars fill based on the user's scrolling progress.


    - **Sound Effects**: 
    - A wind chime/sparkle sound effect plays when the user clicks the folder at the end of the story.

    - **User-triggered Events**: 
    - The main interaction is scrolling. As the user scrolls, the loading bar at the top of the page fills and the percentage changes.
    - The second interaction is clicking the folder at the end of the story. When the folder is clicked, the sound effect plays and the three photos are revealed using a GSAP animation.
    - **Responsive Design**: 
    - The text and image sizes adjust to the size of the screen. I used flexbox to make the images responsive and aligned.
